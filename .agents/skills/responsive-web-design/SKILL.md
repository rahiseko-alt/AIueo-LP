## 🛠️ レスポンシブWebデザイン実践手順

### Step 1: コンテンツ構造とグリッド定義
1. **コンテナ最大幅の設定**:
   - 通常サイト: `max-w-6xl` (1152px) 〜 `max-w-7xl` (1280px)
   - フルワイド / アプリ: `max-w-[1440px]` や `100%` + パディング
2. **段組みのレスポンシブ設計**:
   - 4カラム: `grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-4 gap-6`
   - 3カラム: `grid grid-cols-1 md:grid-cols-3 gap-6`
   - 2カラム（スプリット）: `grid grid-cols-1 md:grid-cols-12`（例: 7:5 や 6:6）

### Step 2: フルードタイポグラフィと余白
1. **見出しフォントサイズ**:
   - `clamp(2rem, 4vw, 4rem)` や Tailwind の `text-3xl sm:text-5xl md:text-6xl` を用いて画面幅に応じて滑らかに伸縮させる。
2. **セクション余白**:
   - モバイル: `py-12 px-6`
   - タブレット: `py-16 px-8`
   - デスクトップ: `py-24 px-10`

### Step 3: タッチターゲットとナビゲーション
1. **モバイルナビゲーション**:
   - 768px未満ではドロワーメニューまたはハンバーガーメニューに自動切り替え。
2. **操作性**:
   - ボタン・リンクのタップ領域は最低 44px × 44px を確保。

### Step 4: マルチデバイス検証（作法）
1. **幅 360px** (iPhone SE): テキストや画像のはみ出し・横スクロールがないか確認。
2. **幅 768px〜820px** (iPad / タブレット): 2カラムへの折り返しやパディングのバランスを確認。
3. **幅 1280px〜1920px+** (PC / ワイド): コンテンツが伸び切らず中央配置で美しく収まっているか確認。

## 💡 Webデザインの黄金律

1. **「固定幅（px）」を避けて「可変幅（%, fr, clamp）」を優先する。**
2. **デバイス名（iPhone用など）ではなく「コンテンツの崩れやすさ」でブレイクポイントを設ける。**
3. **文字の1行の長さ（Line Length）を適切に保ち、可読性を損なわない（35〜45文字）。**
4. **モバイルで情報量を削りすぎず、縦スタックやカルーセルで整理する。**
